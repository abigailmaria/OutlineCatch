# OutlineCatch

Turns task management outlines into accessible HTML files for developers to use in their documentation and projects.

OutlineCatch is aimed at developers who need a straightforward, dependable solution.

**Highlights**

- Turns task management outlines into
- accessible HTML files for developers
- to use in their documentation

## Technology Stack

- python
- python framework (Flask/Django/FastAPI or equivalent)
- Pytest for testing

## Installation

1. Clone the repository: `git clone https://github.com/innayakendya/OutlineCatch.git`
2. `cd OutlineCatch`
3. Install in editable mode: `pip install -e .`

## Configuration

OutlineCatch is configured through environment variables (see `.env.example`). Key options:
- **APP_ENV**: `development` or `production`.
- **PORT**: Port the server listens on.
- **LOG_LEVEL**: `debug`, `info`, or `error`.
